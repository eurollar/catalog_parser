# Отбор артикулов по сертификату

Скрипт выбирает из каталога товары, которые подходят под производителя, товарную группу и маски из сертификата.

Товар принимается, только если совпадают производитель, товарная группа и хотя бы одна маска артикула.

## Допущения

- **Сертификат - JSON.** В ТЗ не указан формат входного файла. JSON позволяет передать производителя, группу и маски без разбора PDF или сканов.
- **Товары берутся из CSV-каталога.** В ТЗ не указан источник товаров. Поэтому скрипт проверяет все строки переданного каталога, но не гарантирует, что в нём есть все товары производителя.
- **Результаты - CSV.** Формат отчёта в ТЗ тоже не задан. CSV можно прочитать без дополнительных библиотек.
- **Поддерживаются маски формата HI-LEX.** Для них есть конкретные правила. Правила других форматов не определены, поэтому скрипт не пытается угадать их.

Сертификат и каталог учебные: они не подтверждают существование товаров или подлинность сертификата.

## Запуск

Нужен Python 3.10 или новее. Устанавливать пакеты не нужно.

Положите входные файлы рядом с `script.py` и выполните из папки проекта:

```bash
python3 -m script
```

Рядом появятся `report.csv` с подходящими товарами без дублей по нормализованному артикулу и `exceptions.csv` с отклонёнными строками и причинами.

Повторный запуск заменяет отчёты. Входные файлы не меняются.

При ошибке входных данных запуск останавливается, предыдущие отчёты сохраняются. Если ошибка возникла при записи `exceptions.csv`, основной отчёт уже может быть обновлён - скрипт сообщит об этом.

Код завершения `0` означает, что оба отчёта сохранены, `1` - ошибку. Отсутствие подходящих товаров не считается ошибкой.

## Входные файлы

Оба файла сохраняйте в UTF-8. Чтобы проверить свои другие данные, замените их содержимое и запустите скрипт снова.

### certificate.json

```json
{
  "manufacturer": "HI-LEX CORPORATION",
  "product_group": "тросы стояночного тормоза",
  "masks": ["4VB****", "4JB****"]
}
```

- `manufacturer` - производитель.
- `product_group` - товарная группа.
- `masks` - непустой список масок.

Все три поля обязательны, названия производителя и группы должны быть непустыми строками. Ключи JSON не должны повторяться.

Маска состоит из трёх заглавных латинских букв или цифр и четырёх `*`. Каждая `*` заменяет ровно одну букву `A-Z` или цифру `0-9`. Например, `4VB****` подходит для `4VB12A3`, но не для `4VB123` или `4VB12-3`.

В сертификате указаны все 38 масок HI-LEX.

### catalog.csv

```csv
article,manufacturer,product_group
4vb12a3,HI-LEX CORPORATION,тросы стояночного тормоза
4QB1234,HI-LEX CORPORATION,тросы стояночного тормоза
```

- Первая строка - заголовки. Обязательны `article`, `manufacturer`, `product_group`; порядок может быть любым.
- Разделитель - запятая. Дополнительные колонки разрешены и не влияют на отбор.
- Заголовки не должны повторяться, а число полей в каждой записи должно совпадать с числом колонок.
- Размер каждого поля - не более 131 072 символов.

Производитель и группа должны точно совпадать с сертификатом, включая регистр и пробелы. В артикулах скрипт переводит латинские буквы в верхний регистр и убирает обычные пробелы по краям. В примере первая позиция подходит, вторая - нет.
